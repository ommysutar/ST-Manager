# @st-manager/utils

Pure, framework-agnostic helper functions (dates, currency, string formatting) shared across all apps and packages.

Status: M1 foundation implemented. Studio-specific helpers (`slugifyStudioName`, `getStudioInitials`, `formatStudioCreatedAt`) are the primary surface; `formatIsoDate` is a low-level internal date helper composed by them, not a general-purpose demo utility.
