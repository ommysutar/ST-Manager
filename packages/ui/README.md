# @st-manager/ui

Shared shadcn/ui primitives and composed React components consumed by both `@st-manager/web` and `@st-manager/desktop`.

- `src/components/` — shadcn/ui primitives and composed widgets
- `src/hooks/` — reusable UI behavior hooks
- `src/lib/` — `cn()` utility and variant helpers
