# @st-manager/theme

Semantic design tokens, theme variants, and generated CSS variables, kept separate from Tailwind build config and React components.

- `src/tokens/` — raw and semantic tokens (color, spacing, typography, radii, shadows)
- `src/themes/` — theme maps composing tokens into light/dark/brand variants
- `src/css/` — generated CSS custom property files

Status: scaffolding only, no application code yet.
