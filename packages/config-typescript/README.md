# @st-manager/config-typescript

Shared `tsconfig` base files extended by every app and package.

- `base.json` — common compiler options for all TypeScript projects
- `react.json` — adds DOM lib and JSX settings for `web` and `desktop`
- `nestjs.json` — adds CommonJS module and decorator metadata settings for `api`

Status: scaffolding only, no application code yet.
